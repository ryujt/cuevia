Cuevia installation and first launch

Requirements
• macOS 14.0 or later
• Google Chrome
• A microphone, internet access, and your OpenAI API key for voice recording and transcription

Installation
1. Drag Cuevia.app from this disk image into Applications.
2. Eject the disk image when the copy finishes.
3. Open Cuevia from Applications. It runs in the menu bar.
4. Press ⌘ Command + ⌃ Control + S or choose Screen Capture… from the menu bar.
   The editor opens in Google Chrome.

Permissions on first launch
• In System Settings → Privacy & Security → Screen & System Audio Recording
  (called Screen Recording on some macOS versions), allow Cuevia to capture your screen.
  If prompted, quit and reopen Cuevia.
• To record audio, allow microphone access for the site in Chrome and for Google Chrome in macOS.
• If macOS blocks the app, ask the distributor for the current notarized release.

Your settings
Open Settings… from the Cuevia icon in the menu bar. Enter your OpenAI API key,
choose a speech transcription model, and save. The default model is whisper-1.
Keep your key private and outside the app bundle.
Settings are stored in ~/Library/Application Support/Cuevia/.env.
The included Cuevia.env.example is a public configuration sample with an empty key.

Log can save captures and text explanations without an API key.
Record and speech transcription require your OpenAI API key. Cuevia sends the audio
to the OpenAI API for transcription. Usage charges may apply to your account.

Launch at login
To launch Cuevia at login, add it in System Settings → General →
Login Items & Extensions. The DMG leaves that setting for you to configure.

Included files
The disk image contains Cuevia.app, an Applications shortcut, this guide, and Cuevia.env.example with an empty key.
The distributor's personal settings, API keys, recordings, original captures, and session materials are excluded.
