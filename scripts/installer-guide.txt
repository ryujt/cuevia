Cuevia installation and first launch

Requirements
• macOS 14.0 or later
• Google Chrome
• For voice recording and transcription: a microphone, an internet connection, and your own OpenAI API key

Install
1. Drag Cuevia.app from this image into the Applications folder.
2. When copying finishes, eject the disk image.
3. Open Cuevia from the Applications folder. It runs in the menu bar.
4. Press ⌘ Command + ⌃ Control + S, or choose "Capture screen…" from the menu bar.
   The editor opens in Google Chrome.

Permissions on first launch
• To capture the screen, allow Cuevia in System Settings → Privacy & Security →
  Screen & System Audio Recording ("Screen Recording" on some macOS versions).
  If macOS asks you to relaunch the app, quit Cuevia and open it again.
• To record voice, allow the site's microphone permission in Chrome and Google Chrome's microphone permission in macOS.
• If macOS blocks the app, ask the distributor for the current notarized release.

Your settings
Open the Cuevia menu bar icon → "Settings…", enter your own OpenAI API key, choose
a transcription model, and save. The default transcription model is whisper-1.
Never share your key with others or put it inside the app bundle.
Settings are stored in ~/Library/Application Support/Cuevia/.env.
The Cuevia.env.example included in this image is a public reference file with an empty key.

Screens and text notes can be saved without an API key.
Voice recording and transcription require your own OpenAI API key. Recordings are sent
to the OpenAI API for transcription, and your API usage may be billed.

Launch at login
This DMG does not register Cuevia to launch at login. If you want that, add Cuevia
yourself in System Settings → General → Login Items & Extensions.

Included files
Only Cuevia.app, a link to the Applications folder, this guide, and Cuevia.env.example with an empty key.
The distributor's personal settings, API keys, recordings, original screens, and session data are not included.
